2 / Modulation

runtime carrier: 25–50 kHz, 50% duty, 38 kHz default
RMT TX → S8050 → 600 mm pair → 39 Ω → VSMB1940X01 940 nm
                                            ↓ spoke: transmission 1.00 → 0.05
                                      VEMD10940FX01

Typical installed LED current: 45.02 mA including 0.3168 Ω maximum harness/contact loop resistance. At 60 km/h and the default, one blockage removes 6.40 carrier cycles.

Reliability mechanism: DC sunlight and slow shadows contain little energy at the selected carrier. The AC-coupled receiver accepts that temporal signature, the comparator restores logic edges, and RMT classifies a spoke only when several consecutive carrier cycles disappear. A single amplitude sample would not provide those independent rejection mechanisms.

No prebuilt carrier receiver and no AGC. The configured carrier range is an installed-filter constraint. Nominal simulated band-pass swing is 0.364 Vpp. The VEMD10940FX01 includes an 830–950 nm matched daylight-blocking optical filter. Sunlight still contains 940 nm energy; TIA headroom, AC filtering and carrier-loss timing provide the remaining rejection.

4 / Demodulation and capture

selected carrier → comparator carrier
                 → RMT RX carrier removal at 0.66·f_TX
                 → missing-carrier duration
                 → 70–600 µs detector
                 → timestamp → pattern learner

RMT RX is used because it removes the carrier in hardware. MCPWM Capture is appropriate only after an external envelope detector; otherwise it exposes each carrier edge.

ESP-IDF abstraction used: TX/RX channel allocation, copy encoder, rmt_apply_carrier, receive callback, rmt_receive and rmt_transmit. GPIOs, RMT resolution, TX duty, RX frequency ratio, RX duty, glitch filter and interval limits share one runtime config. The default 0.66 RX/TX ratio follows Espressif's 25/38 kHz tolerance example.

Core: C99, caller-owned state, no heap, no RTOS dependency. Count matching compares adjacent N-length interval windows for N=16–48. Locked LUT cells use an 0.08 EMA with bounded residual rejection. Uniform spacing is not sufficient to identify an absolute spoke count and therefore remains confidence-limited.

7 / Simulation scope

Numerical transient: optical inverse-square scaling, cable drop, component RC poles, ambient DC, shot/Johnson/op-amp noise plus adjustable interference, comparator propagation delay/hysteresis and RMT missing-carrier behavior. Every window contains a centered physical blockage. 10,000-case sweep: 99.80% pass; p01 decision margin 1.29×; p01 TIA headroom 0.44 V. The sweep is not a substitute for optical alignment, sunlight, contamination or wheel tests.
