4 / Demodulation and capture

selected carrier → comparator carrier
                 → RMT RX carrier removal at 0.66·f_TX
                 → missing-carrier duration
                 → 70–600 µs detector
                 → timestamp → pattern learner

RMT RX is used because it removes the carrier in hardware. MCPWM Capture is appropriate only after an external envelope detector; otherwise it exposes each carrier edge.

5 / Reusable C interfaces

moduleinput → output
ir_spoke_configruntime carrier/duty → validated RMT settings
ir_spoke_geometrywheel geometry/speed → timing bounds
ir_spoke_detectorblockage duration → accept/reject + counters
ir_spoke_patternaccepted timestamps → count/confidence/LUT/speed
ir_spoke_pipelinedetector + pattern composition
ir_spoke_rmt_adapterESP-IDF RMT ISR/task → portable pipeline

Core: C99, caller-owned state, no heap, no RTOS dependency. Count matching compares adjacent N-length interval windows for N=16–48. Locked LUT cells use an 0.08 EMA with bounded residual rejection. Uniform spacing is not sufficient to identify an absolute spoke count and therefore remains confidence-limited.

7 / Simulation scope

Numerical transient: optical inverse-square scaling, cable drop, component RC poles, ambient DC, filtered input noise, comparator hysteresis and RMT missing-carrier behavior. 10,000-case sweep: 99.80% pass; p01 decision margin 1.29×; p01 TIA headroom 0.44 V. The sweep is not a substitute for optical alignment, sunlight, contamination or wheel tests.
