The carrier is continuous. A spoke removes approximately 6.40 carrier cycles at 60 km/h. Nominal LED current is 45.38 mA. The simulation uses datasheet reverse-light current scaling and an explicit alignment factor.

4. Digital demodulation

comparator 38 kHz logic
  → RMT RX carrier removal configured at 25 kHz
  → missing-carrier interval
  → accept only 70…600 µs
  → timestamp edge
  → adaptive interval matcher

RMT is selected over MCPWM Capture because RMT removes the carrier in hardware. MCPWM Capture would process every 38 kHz edge unless an external envelope detector were added.

5. Spoke-count and interval-map algorithm

  1. Store accepted edge-to-edge intervals in a fixed circular buffer.
  2. For each candidate count N=16…48, compare two adjacent N-interval sequences using normalized absolute error.
  3. Select the lowest-error fundamental; lock only if error < 0.035 and best/second-best separation > 0.08.
  4. Initialize one interval-LUT cell per spoke.
  5. For each revolution, reject residuals outside max(80 µs, 3.5·0.08·previous).
  6. Update accepted cells by EMA: LUT ← LUT + 0.08·(measurement−LUT).
  7. Wheel period is the sum of the LUT; f_wheel=10⁶/sum(LUT).

Observability limit: perfectly uniform intervals do not identify the absolute spoke count. The implementation keeps confidence low in that case.
